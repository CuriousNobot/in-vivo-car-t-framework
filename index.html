质量目标产品概况Quality Target Product ProfileQTPP
从质量角度描述预期产品特征，为药学开发与质量控制提供依据；与整体临床开发目标区分。
核酸载荷Nucleic Acid Payload
被递送的治疗性核酸及适用的辅助核酸；载荷身份、结构和功能按实际产品分别定义。
脂质纳米颗粒Lipid NanoparticleLNP
用于递送载荷的脂质组装颗粒；组分名称、数量或粒径不能代替实际结构、质量和功能证据。
信使 RNAMessenger RNAmRNA
作为蛋白表达模板的 RNA；完整性、表达调控、杂质及实际功能需要相互衔接。
嵌合抗原受体Chimeric Antigen ReceptorCAR
整合抗原识别、膜定位与胞内信号的工程受体；表达与细胞功能属于不同证据。
T 细胞受体T-Cell ReceptorTCR
TCR 产品需评价实际抗原识别限制、肽–HLA 相关性及适用的受体错配风险。
T 细胞衔接器T-Cell EngagerTCE
同时结合 T 细胞与目标细胞相关分子的治疗性分子；体内编码产品还需证明蛋白生成、分泌、暴露和活性。
调节性 T 细胞Regulatory T CellTreg
以免疫调节功能为主要任务的 T 细胞；CAR-Treg 需验证选择性、抑制功能和谱系稳定性。
靶向配体／抗原结合域Targeting Ligand / Antigen-binding Domain
载体靶向配体决定递送识别；CAR 抗原结合域决定疾病抗原识别。两者不可互相替代。
亲和力／亲合力Affinity / Avidity
亲和力描述单个结合位点的相互作用；亲合力描述多重结合的整体作用。功能性亲合力需结合实际细胞与功能读数解释。
非翻译区Untranslated RegionUTR
RNA 的非翻译序列区域；其作用需与实际载荷、细胞状态和表达持续时间一起评价。
帽结构／多聚腺苷酸尾Cap Structure / Poly(A) Tail
mRNA 的结构与表达调控要素；结构身份、完整性和功能关系按产品验证。
体外转录／双链 RNAIn Vitro Transcription / Double-stranded RNAIVT / dsRNA
前者为 RNA 生产过程，后者可为实际载荷或相关杂质；对质量与免疫反应的影响按产品及方法评价。
表观 pKaApparent pKa
用于描述制剂体系的表观酸碱／质子化特征；pKa 为酸解离常数的负对数，成品表观值不能与游离分子值混用。
氮／磷比Nitrogen-to-Phosphate RatioN/P Ratio
按明确计量口径计算相关氮与核酸磷的比例；不能与总脂质／RNA 质量比互换。
多分散性指数Polydispersity IndexPDI
粒径分布的物理表征指标；解释依检测方法与样品条件，不能替代功能效力。
切向流过滤Tangential Flow FiltrationTFF
药学生产中的过滤、纯化或浓缩相关工艺；控制目的和对产品质量的影响按实际工艺论证。
药学、生产与质量控制Chemistry, Manufacturing and ControlsCMC
覆盖产品组成、制造、分析方法、质量控制和稳定性等资料；具体边界及成熟程度随产品与阶段确定。
关键质量属性／关键工艺参数Critical Quality Attribute / Critical Process ParameterCQA / CPP
是否属于“关键”须由产品质量、安全性、效力及工艺风险的数据论证，不能仅凭行业常见指标判定。
活性物质／制剂Drug Substance / Drug ProductDS / DP
申报中的产品与制造边界按实际注册定义确认；核酸原液或单个组分不自动等同整个产品的活性物质。
生物学效力Potency
质量控制中的机制相关生物学活性／效力，亦有“效价”的译法；效力测定及计量单位须明确。它不等同临床有效性或病毒滴度。
药代动力学／药效学Pharmacokinetics / PharmacodynamicsPK / PD
分别描述药物的体内过程与生物学作用；体内 CAR-T 还需区分载荷、受体表达、工程细胞及疾病效应的时程。
临床有效性Clinical Efficacy
在适用患者、终点和研究设计下评价临床治疗作用；药效学标志物或靶细胞清除不能自动证明临床获益。
生物分布Biodistribution
按明确检测实体评价组织、体液或细胞中的分布与持续存在；器官信号、细胞摄取及功能递送分别解释。
细胞摄取／内化／内吞Cellular Uptake / Internalization / Endocytosis
摄取是细胞获得材料的现象，内化强调进入细胞，内吞是具体机制；膜融合路线不强制套用内吞。
内体逃逸Endosomal Escape
载荷跨越内体膜进入适用细胞区室的过程；膜损伤、颗粒解体、完整可用载荷和最终表达属于不同证据。
核酸解离／释放Nucleic Acid Unpacking / Release
核酸从递送体系中解离并成为可用载荷；与跨内体膜的逃逸及病毒脱壳分别评价。
转染／转导Transfection / Transduction
非病毒核酸导入通常称转染，病毒载体介导的基因转移称转导；混合机制目录优先使用中性的“递送”。
表达持续时间／细胞持续性Expression Duration / Cell Persistence
受体表达保留多久与工程细胞持续存在多久分别测量，二者也不等同疾病药效或临床缓解持续时间。
基因编辑／基因整合Gene Editing / Gene Integration
只在实际构型需要预期 DNA 编辑或整合时启用相关模块；工具表达、遗传结果与改变后的功能分别验证。
可比性／证据桥接／技术转移Comparability / Evidence Bridging / Technology Transfer
分别指变更前后产品的比较、旧证据对新版本的支持论证，以及制造／分析知识和方法的转移。符合放行标准不自动完成这三项工作。
免疫原性／抗药抗体Immunogenicity / Anti-drug AntibodyADA
免疫反应的对象、检测方法及临床影响分别界定；载体组分、靶向配体与表达产物可能具有不同风险。
免疫重建／免疫重置Immune Reconstitution / Immune Reset
免疫重建描述免疫细胞与功能恢复；免疫重置属于需要疾病机制证据支持的假说，不能由靶细胞回升自动判定。
细胞因子释放综合征Cytokine Release SyndromeCRS
发生、严重程度、时序和管理需与实际产品、患者及方案对应。
免疫效应细胞相关神经毒性综合征Immune Effector Cell-associated Neurotoxicity SyndromeICANS
需与实际治疗的神经毒性证据和鉴别诊断对应，不能直接照搬另一产品的发生率或管理结论。
病毒／载体脱落Virus / Vector Shedding
指载体相关材料经体液等排出体外；核酸检出不自动证明感染性或传播，也不同于 PEG 脂质从颗粒表面的脱附。
包膜递送载体／病毒样颗粒Enveloped Delivery Vehicle / Virus-like ParticleEDV / VLP
名称不能代替实际载荷、结构、入胞机制、质量属性及遗传作用的产品定义。
首次人体试验First-in-Human TrialFIH
首次人体给药需有产品特异性的起始方案与安全依据；申请获批不等于已完成临床概念验证。
临床试验申请／研究性新药申请Clinical Trial Application / Investigational New Drug ApplicationCTA / IND
按地区记录实际申请、批准及试验范围；IND 为美国监管用语，不能与其他地区状态直接互换。
研究者发起试验／生物制品许可申请Investigator-initiated Trial / Biologics License ApplicationIIT / BLA
IIT 是研究组织形式；BLA 是美国生物制品许可申请。研究形式、监管批准和注册进展分别记录。
长期随访Long-term Follow-upLTFU
按实际遗传机制、持续性及迟发风险设计；不为全部 in vivo CAR-T 产品预设同一随访时长。
药品生产／非临床研究／临床试验质量规范Good Manufacturing Practice / Good Laboratory Practice / Good Clinical PracticeGMP / GLP / GCP
分别适用于相应生产、研究及试验活动；项目适用性与质量要求按阶段、地区及研究性质确认。
实施自由度Freedom to OperateFTO
评估技术实施与第三方权利的关系；专利授权、有效性、权利范围及许可边界分别审查。
