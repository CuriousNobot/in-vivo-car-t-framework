## 这一版做什么

v7.0 把 v6.4 的认识论框架改成可执行的尽调工具。RNA-LNP 与靶向慢病毒不再共用同一套节点：前者围绕瞬时表达、给药周期、配体与肝/脾分布、重复给药免疫原性、mRNA/制剂与冷链、剂量–暴露–药效；后者围绕整合与插入突变、假型化靶向、长期随访、复制型慢病毒（RCL）、载体产能，以及单次给药后不能停药的安全含义。

页头可直接进入红旗清单、Scorecard、Go/No-Go、数据室清单和竞争格局。Scorecard 使用五档评级和审阅权重，不换算总分；勾选与评级只保存在本机浏览器。

v6.4 的参考文献整表保留（RNA-LNP 91 条，慢病毒 36 条），并按 2026-10-12 的公开来源补充竞争、交易、监管和 ESO-T01 对账条目。未核实的金额、交割状态和临床数字留空或标明证据等级。

## 如何使用

1. 在标题旁选择 **RNA-LNP / Lentiviral（慢病毒）** 路线。切换时保留可对应的章节；两条路线的机制节点不同，会落到各自对应的技术问题。
2. 先读第 0 章的评估纪律，再用第 7 章做判断，用第 8 章发数据室补件。技术章节用来填写这些工具。
3. 使用中文或英文关键词搜索当前路线。
4. 点击正文“信息来源”后的编号查看依据和证据边界，再返回原技术点。
5. 使用标题旁的太阳／月亮按钮切换浅色／深色模式。

[直接打开慢病毒路线](https://curiousnobot.github.io/in-vivo-car-t-framework/?route=lv)
