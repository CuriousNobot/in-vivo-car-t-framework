## 使用方法

- 标题右侧的 RNA-LNP / Lentiviral 图标切换路线，月亮／太阳图标切换主题。
- 通过三级编号目录、当前位置和章节导航阅读；深层技术细节放在正文中。
- 检索框支持中文、英文术语及主题编号；每次只检索当前路线。
- 术语索引与参考资料可折叠，来源链接可返回原章节。

两条路线按各自机制编排，不要求相同章节编号。六个一级模块为：产品定义与临床定位；产品设计与体内作用机制；药学开发、制造与供应；非临床研究与人体转化；临床开发与注册策略；数据核验、知识产权与综合评价。

RNA-LNP 重点包括 CAR 编码 RNA、脂质及靶向元件、体内分布、内体逃逸、表达时程及再给药。Lentiviral 重点包括载体基因组属性、包膜架构、功能转导、持续表达、整合与克隆性。两条路线分别说明技术选择、关键难点、尽调证据及结果解释。
