## 如何使用

1. 在标题旁选择 **RNA-LNP / Lentiviral（慢病毒）** 路线。每枚圆形图标下方显示路线名称，选中项以底色和勾选标明；更新日期及分级目录也标明当前路线。两条路线位于同一个网页中，各自提供完整内容；切换时保留可对应的章节位置。
2. 使用最多三级的编号目录定位主题。阅读区显示完整路径，可逐级返回；每章的内容导航列出实际内容块，点击可跳转。更深技术细节直接放在正文中。
3. 使用中文或英文关键词搜索当前路线，例如“内体逃逸”或“Vector Copy Number”。
4. 点击正文“信息来源”后的编号查看依据，再返回原技术点；页面提供中英文术语索引。
5. 使用标题旁的太阳／月亮按钮切换浅色／深色模式，下方文字标明可切换的主题。三个圆形图标均使用下方文字说明，不另加路线外框；术语索引和参考资料入口在检索、问候这一排。浏览器会记住主题偏好及各路线的阅读位置。

## 内容范围与阅读边界

面向制药企业专业尽调团队，围绕体内 CAR-T 的产品定义、载荷与递送、药学开发与质量控制（CMC）、药效与安全性、转化与临床开发，以及数据可靠性、技术权利和实施能力组织内容。主要技术点介绍背景与关键概念、技术难点、设计策略及所需证据。

LNP / RNA 与靶向慢病毒分别组织完整内容，结合各自的表达时程、递送或转导过程、生成细胞、CMC、转化和临床特点进行核验。各章保留背景、技术难点与证据要求，并按主题增加关键机制、设计判断、策略取舍及核验细节。章节重点先解释与本章主题的关系，再展开技术问题；各内容块使用标题和统一分隔线，并全部列入本章导航。

页头采用紧凑布局：标题旁为路线和主题切换，标题和英文名称下方显示更新日期与版本；下一排放置检索、Curious_RZ 像素小猫问候，以及术语和参考资料入口，窄屏自动调整布局。电脑端检索区与下方目录等宽。小猫动作放慢，并在深度伸展时停留；深色主题采用中性炭灰色阅读背景，保持文字对比度。

这是通用技术尽调框架。具体条目的适用性及证据要求，应结合实际产品、开发阶段、目标地区和正式监管沟通判断。论文、官方资料和工业界公开材料均注明来源，公开材料不能替代待尽调企业的原始数据。资料核验日期为 2026-10-09。
